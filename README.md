# 🛒 E-Commerce Web Platform (Plataforma de Comercio Electrónico)

Plataforma web de comercio electrónico desarrollada de manera integral, diseñada para gestionar el catálogo de productos, el flujo completo de compras en línea (carrito y checkout) y la autenticación de usuarios.

## 🚀 Módulos y Funcionalidades Principales

* **Autenticación y Sesiones (`index.php`, `login.php`, `register.php`, `logout.php`):** Sistema robusto para el registro, inicio de sesión y control de acceso de clientes.
* **Catálogo y Detalle de Productos (`productos.php`, `product.php`):** Visualización general del catálogo e interfaces detalladas de artículos individuales.
* **Gestión de Compras (`carrito.php`, `cart.php`):** Control dinámico de artículos seleccionados por el usuario.
* **Proceso de Pago y Confirmación (`checkout.php`, `confirmacion.php`):** Flujo seguro de salida, validación de compra y emisión de confirmación de pedido.

## 🛠️ Stack Tecnológico

* **Frontend:** HTML5, CSS3 (con estilos personalizados en `/css`), JavaScript (`/js`).
* **Backend:** PHP.
* **Base de Datos:** Scripts y esquemas SQL centralizados en la carpeta `/sql`.

## 📦 Estructura del Proyecto

* `/css`, `/js`, `/includes` — Recursos visuales, scripts de interactividad y componentes de la interfaz.
* `/sql` — Archivos de configuración y respaldo de la base de datos relacional.
* `carrito.php` / `cart.php` — Lógica de gestión del carrito de compras.
* `checkout.php` / `confirmacion.php` — Módulos del proceso final de compra.
* `index.php`, `login.php`, `register.php`, `logout.php` — Vistas principales y control de usuarios.
* `product.php` / `productos.php` — Visualización y administración de inventario en tienda.
